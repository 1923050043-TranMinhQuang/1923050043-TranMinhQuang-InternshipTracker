# Internship Pipeline Tracker (Checkpoint)

Ứng dụng di động được xây dựng bằng **React Native (Expo SDK 56+)**, **Expo Router**, và **TypeScript**, sử dụng **Zustand** để quản lý trạng thái tập trung. Ứng dụng giúp sinh viên theo dõi tiến trình nộp hồ sơ thực tập tại nhiều công ty và nhiều vị trí khác nhau.

## Yêu cầu hệ thống
- Node.js (phiên bản LTS khuyến nghị)
- npm hoặc yarn
- Expo Go (nếu chạy trên thiết bị điện thoại thực tế)
